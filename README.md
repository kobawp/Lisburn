## 💡 Why Lisburn?
Most to-do apps and calendar tools assume tasks belong to strict dates or hours. But real life is full of irregular tasks:
- *When did I last change my car's oil or cabin filter?*
- *When did I last replace the toothbrush or contact lenses?*
- *When did I last deep clean the coffee machine or water the plants?*

Lisburn tracks the elapsed time since you last completed a task, automatically notifys when something is overdue, and keeps a complete audit history without cluttering your traditional calender.

---

## 🚀 How to use? Install as Web App (PWA)
1. Visit **[lisburn.ai.studio](https://lisburn.ai.studio/)** in Safari (iOS) or Chrome (Android / Desktop).
2. On **iOS**: Tap the **Share** icon in Safari and select **"Add to Home Screen"**. Make sure to select **"Open as Web App"**.
3. On **Android / Desktop**: Tap the install prompt or menu and select **"Install App"** / **"Add to Home screen"**.
4. Enjoy free instant access, native home screen icons, and persistent cross-device syncing!

## ✨ Key Features

### ⏱️ Activity Tracking
- **One-Tap Completion**: Log a task in seconds
- **Precise Elapsed Time**: See live counts showing exactly how long ago a task occurred (hours, days, weeks, months).
- **Retroactive Logging**: Forgot to log something yesterday? Pick past dates and times effortlessly.

### 📜 Full Completion History & Notes
- **Detailed History Log**: Review every time you completed a task with timestamps and audit history.
- **References**: Attach references to individual completions (e.g., mileage on oil change).
- **Log Editing**: Edit past/accidental logs easily.

### 🔔 Smart Intervals & Statuses
- **Custom Reminder Intervals**: Set optional, flexible reminders (hours, days, weeks, months).
- **Push Notifications**: Get notified when tasks are overdue.
- **Quiet Hours**: Set custom hours where notifications aren't sent.

### 🗂️ Custom Sorting & Ordering
- **Manual Ordering**: Reorder tasks in custom order.
- **Instant Sorting Options**: Sort by Last Done, Name, or Creation Date.
- **Filter & Search**: Type to instantly search your tasks.

### 🎨 Personalization
- **Custom Icons**: Assign custom icons/emojis to your tasks for easy viewing.
- **Time Zones**: Choose any time zone

### 🎨 Syncing
- **Google Sign-In**: Sign in with a Google Account to automatically sync tasks and settings through multiple devices
- **Backup**: Import and Export JSON files to backup and restore if you prefer to stay offline

### 📱 Modern Progressive Web App (PWA)
- **Install to Home Screen**: Works like a native iOS and Android application
- **Real-Time Cloud Sync**: Powered by Firebase Firestore for seamless instant sync across all your devices.
